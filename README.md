4. 技術勾選
依目前程式實作整理，對照課程第 3～7 週技術勾選表與投影片。
[x] GPIO 輸出／複用功能：四路 TIM3 PWM 驅動 LED。
[x] GPIO 輸入：PA0 接實體按鈕，使用內部上拉。
[x] RCC 與 PLL：HSI 16 MHz 經 PLL 產生 170 MHz 系統時脈。
[x] Timer：TIM3 提供 PWM 計數與亂數種子取樣所用的計數值。
[x] PWM：四路獨立亮度，呈現全亮、熄滅與呼吸。
[x] UART 傳送／接收：LPUART1，採輪詢接收。
[x] EXTI 外部中斷：PA0 下降沿觸發重開要求。
[x] NVIC：啟用 EXTI0，優先權為 2。
[x] 軟體按鈕防重複觸發：200 ms 內忽略重複中斷。
[ ] UART 中斷接收＋環形緩衝：目前未實作。
[ ] Timer 週期中斷：呼吸亮度由主迴圈更新。
[ ] Timer 輸入捕捉：目前未使用。
<details>
<summary>展開 PWM 設定與計算</summary>
參數	設定
TIM3 時脈	170 MHz
Prescaler／Counter Period	169／999
PWM 模式／極性	PWM mode 1／High
比較值	0 熄滅、1000 全亮
呼吸週期	1 秒漸亮＋1 秒漸暗
PWM 頻率：`170,000,000 ÷ (169 + 1) ÷ (999 + 1) = 1000 Hz`。
</details>

5. 腳位與接線
腳位	功能	用途
PA6	TIM3_CH1	LED 1：猜測第 1 位
PA7	TIM3_CH2	LED 2：猜測第 2 位
PB0	TIM3_CH3	LED 3：猜測第 3 位
PB1	TIM3_CH4	LED 4：猜測第 4 位
PA0	GPIO_EXTI0	重來按鈕：上拉、下降沿觸發
PA2／PA3	LPUART1_TX／RX	透過板載 ST-LINK VCP 與電腦通訊
PA13／PA14	SWDIO／SWCLK	ST-LINK 燒錄與除錯
GND	共地	LED 負極及按鈕另一端

接線項目	方式／注意事項
LED 正極	輸出腳位 → 330 Ω～1 kΩ 電阻 → LED 正極；每顆各用一顆電阻
LED 負極	接板子 GND
麵包板按鈕	接 PA0 與 GND；選用按下後才導通的兩端
板載 B1／LD2	PC13／PA5 未作為本遊戲的主要按鈕與四路提示燈

7. 程式結構與分工
檔案	主要職責
Src/main.c	初始化、隨機答案、猜測比對、LED 更新、重開處理
Src/stm32g4xx_it.c	EXTI0 中斷入口，轉交 HAL 處理
Src/stm32g4xx_hal_msp.c	周邊時脈與複用腳位初始化
Inc/main.h	共用宣告與腳位定義
Guess1A2B.ioc	CubeMX 設定
`UART_GUI.py`	串口連線、輸入檢查、結果顯示及歷史紀錄

執行位置	工作分配
按鈕 ISR／回呼	判斷 200 ms 間隔，設定 `restart_requested`；不執行遊戲比對或 UART 傳送
STM32 主迴圈	處理重開、輪詢接收字元、收到換行後比對，持續更新四路 PWM
Python GUI	背景執行緒接收串口，透過佇列交給介面執行緒顯示；A／B 仍由 STM32 判斷
<details>
<summary>展開隨機答案產生方式</summary>
階段	處理方式
第一次初始化	首次收到非換行字元，或首次按下重來按鈕時取樣玩家操作時間
建立種子	使用 `HAL_GetTick()` 與 TIM3 計數值，交給 `srand()`
產生答案	`GenerateAnswer()` 使用 `rand()`，從 0～9 取出四個不重複數字
後續重開	延續亂數序列，排除與上一局完全相同的答案
隨機性範圍	偽隨機方式，非硬體真亂數
</details>

10. 已知限制與後續改善
目前限制	後續改善方向
UART 採輪詢，快速連續傳送時可能漏字	改為中斷／DMA 接收與環形緩衝
呼吸效果由主迴圈更新	加入固定週期排程或 Timer 中斷
按鈕採 200 ms 簡易防重複觸發	量測彈跳並改善去彈跳方式
猜中後需按實體按鈕換題，且未鎖定後續輸入	加入明確遊戲結束狀態與自動換題選項
GUI 紀錄只存於記憶體，重新連線不會重設 STM32	增加紀錄匯出及狀態同步
